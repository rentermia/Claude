# My Businesses — Organized

This workspace keeps my two LLCs organized, **separately**, so Claude can help with both
without mixing them up.

```
owner/                 ← my week, my deadlines, quick notes (both businesses, labeled)
rental/                ← Car rental LLC
custom-shop/           ← Car customization shop LLC
between-businesses/    ← anything that crosses between the two LLCs
```

## How to use it with Claude
Just talk normally, and say which business when you can:
- "Rental: add a task to renew insurance on the Tahoe by Dec 1"
- "Shop: new job — wrap and tint for a customer, quoted $3,200, due Friday"
- "Log a $240 parts expense for the shop"
- "What's on my plate this week?"
- "Draft a reply to a customer asking about weekend rental rates"

## First step
Fill in the `business-profile.md` in each business folder (or just tell Claude the details
and it will fill them in).
